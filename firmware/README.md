# Паркинг на MQTT

```
Приложение ──wss:8884──►  MQTT-брокер  ◄──mqtts:8883── ESP32 паркинг 1 (шлагбаум + ворота, 2 реле)
                          (HiveMQ Cloud) ◄──mqtts:8883── ESP32 паркинг 2 (ворота, 1 реле)
```

Приложение публикует команду, ESP замыкает реле на 1 секунду и отвечает `ack`.
«Открыто» в приложении появляется только после ответа контроллера. Если ESP
пропала из сети, брокер сам публикует `offline`, и в приложении видно
«Контроллер не в сети».

## Сейчас

Приложение и обе прошивки работают через **публичный брокер `broker.emqx.io`**
(ESP: порт 8883 TLS, приложение: `wss://broker.emqx.io:8084/mqtt`, префикс `aristokrat`).
Он бесплатный, но без паролей — любой, кто знает топик, может отправить команду.
Для постоянной работы переходите на HiveMQ Cloud (ниже) и меняйте адрес в прошивках и в `.env`.

Пины: паркинг 1 — шлагбаум GPIO 12, ворота GPIO 5 (реле активно высоким уровнем);
паркинг 2 — ворота GPIO 2 (реле активно низким уровнем).

## 1. Брокер — HiveMQ Cloud (бесплатно)

1. Зарегистрируйтесь на https://www.hivemq.com/mqtt/ → **Start free** → создайте кластер **Serverless (Free)**.
2. В кластере **Access Management** создайте два логина:
   - `esp-parking` — для обоих контроллеров;
   - `app` — для приложения.
3. На вкладке **Overview** скопируйте адрес кластера, например `abc123.s1.eu.hivemq.cloud`.
   - ESP: порт **8883** (TLS)
   - Приложение: `wss://abc123.s1.eu.hivemq.cloud:8884/mqtt`

Бесплатного тарифа хватает с запасом: 100 подключений, 10 ГБ трафика в месяц.

> Открытые брокеры вроде `broker.hivemq.com` или `broker.emqx.io` для ворот
> не подходят: там нет паролей, и любой человек может отправить команду
> в ваш топик.

## 2. Прошивка ESP32

1. Arduino IDE → Library Manager → **PubSubClient** (Nick O'Leary).
2. Откройте нужный скетч — каждый целиком в одном файле:
   - паркинг 1 → `parking1/parking1.ino`
   - паркинг 2 → `parking2/parking2.ino`
3. Заполните блок **НАСТРОЙКИ** в начале файла: Wi-Fi, адрес брокера, логин `esp-parking` и пароль.
   При необходимости поменяйте пины и `RELAY_ACTIVE_LOW`.
4. Плата **ESP32 Dev Module** → Upload. В Serial Monitor (115200) должно появиться `[mqtt] connected`.

> После того как впишете пароли, не коммитьте эти файлы в git с паролями.

Подключение реле:

| Контроллер | GPIO 26 | GPIO 27 |
|---|---|---|
| Паркинг 1 | шлагбаум | ворота |
| Паркинг 2 | ворота | — |

## 3. Приложение

Скопируйте `.env.example` в `.env.local` в корне проекта, вставьте адрес и логин `app`, затем:

```bash
npm run build && npx cap sync
```

## Топики

| Топик | Кто пишет | Что внутри |
|---|---|---|
| `aristokrat/parking1/status` | ESP (retained, LWT) | `online` / `offline` |
| `aristokrat/parking1/barrier/cmd` | приложение | id запроса |
| `aristokrat/parking1/barrier/ack` | ESP | тот же id |
| `aristokrat/parking1/barrier/state` | ESP | `1` реле замкнуто / `0` |
| `aristokrat/parking1/gate/...` | | ворота паркинга 1 |
| `aristokrat/parking2/gate/...` | | ворота паркинга 2 |
| `aristokrat/parking1/info` | ESP (retained) | `{"rssi":-60,"uptime":123,"ip":"..."}` |

Проверить без приложения можно из [MQTT Web Client](https://www.hivemq.com/demos/websocket-client/)
от HiveMQ: опубликуйте любое слово в `aristokrat/parking1/barrier/cmd`, и реле щёлкнет.

## Надёжность

- Реле выключается по таймеру внутри ESP, даже если в этот момент пропал интернет.
- Повторно доставленная команда (QoS 1) не открывает ворота второй раз.
- Команды, отправленные, пока ESP была офлайн, не копятся и не срабатывают позже.
- Wi-Fi и MQTT переподключаются сами, с увеличивающейся паузой.
